# @securelink/core

Shared SecureLink client foundation (session, transport, anonymous / customAuth pipeline).

Most apps should use a platform package instead:

- [`@securelink/web`](https://www.npmjs.com/package/@securelink/web)
- [`@securelink/react-native`](https://www.npmjs.com/package/@securelink/react-native)
- [`@securelink/extension`](https://www.npmjs.com/package/@securelink/extension)

## Install

```bash
npm install @securelink/core
```
